# WebRTC & Network Protocol Lab

Mô hình truyền nhận P2P Real-Time, phân tích SDP & so sánh TCP vs UDP trên trình duyệt Web.

Demo trực tiếp (sau khi bật GitHub Pages): `https://<username>.github.io/WebRTC/`

## Chạy local
Mở `index.html` bằng Live Server (VSCode) để thực hành 2 tab / 2 máy LAN.

## Deploy GitHub Pages
1. Push repo này lên GitHub với tên `WebRTC`
2. Vào Settings > Pages > Deploy from branch > `main` / `/ (root)`
3. Truy cập domain miễn phí được cấp.
